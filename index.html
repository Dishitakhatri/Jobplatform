Setup guide
1
Download the bot script
Click "Download script" below. Save job_agent_bot.py anywhere on your computer.
2
Install dependencies
pip install playwright anthropic
playwright install chromium
3
Get Anthropic API key
Visit console.anthropic.com → API Keys → Create. Free credits included. Add it to the script as ANTHROPIC_API_KEY.
4
Fill in your credentials
Open the script and add your LinkedIn email/password and paste your resume text. All stays on your machine.
5
Run before bed
python job_agent_bot.py
Leave your laptop open. Wake up to your CSV application log.
6
Schedule automatically (optional)
Mac/Linux cron: 0 23 * * * python /path/job_agent_bot.py
Or deploy to a free server on Railway/Render so your laptop stays off.
API configuration
🔒
API key secured via Cloudflare Worker
Your key never appears in the browser. All AI calls route through your private proxy.
To update your Worker URL, edit the PROXY_URL constant in the HTML source and re-upload to GitHub.
Data management
All your data (profile, jobs, analyses) is saved in your browser's localStorage. It persists between sessions.
